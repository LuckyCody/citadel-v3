# Contributing

Citadel is not currently accepting external code contributions (pull requests).
As a security-critical cryptographic library, changes to the cryptographic core
and key-management logic are kept under tight, single-author review.

This may change in the future. If it does, this document will be updated with
the contribution process and any Contributor License Agreement requirements
(Citadel is dual-licensed under AGPL-3.0-or-later and a commercial license —
see [README.md#license](README.md#license) — and any contribution process
would need to account for that).

## What's welcome

- **Bug reports and vulnerability reports** — see [SECURITY.md](SECURITY.md)
  for the disclosure process. Do not open a public issue for a security bug.
- **Non-security issues** — open a GitHub issue describing the problem,
  ideally with a minimal reproduction.
- **Questions** — see [SUPPORT.md](SUPPORT.md).

## Code of Conduct

Participation in issues and discussions is governed by
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
